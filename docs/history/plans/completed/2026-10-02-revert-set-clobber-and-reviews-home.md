## Terms

- **check-landed**: the new post-landing sweep mode of `scripts/reverse_squash_guard.py`; given a landed commit, its source branch, and the pre-landing tip, it flags first-parent deletions whose content was touched after the merge base of the source branch and the pre-landing tip.
- **Foreign deletion**: a deletion of a path whose content at the pre-landing tip was added or modified in the merge-base range, that is, content the landing's own branch never saw; the clobber signature.
- **Ack (fold-and-delete)**: the sweep's suppression of a flagged deletion for paths the run manifest owns as fold-and-delete archives (origin folds, backlog deletions), passed as `--ack-deleted` repeats or an `--ack-file` newline list; suppression is exact path identity (a prefix or directory entry suppresses nothing and warns as unused); acks are bounded to the fold-ack trees, the guard constant `FOLD_ACK_TREES = ("docs/history/plans/", "docs/history/backlog/")`, deliberately wider than `ARCHIVE_DIRS` (which carries the `/completed/` component) because fold-and-delete targets sit flat; an entry outside them is a guard misconfiguration (tool failure), and an entry matching no deleted path prints a warning line; the mirror ack of `check-staged` is a different mechanism and stays sha-keyed.
- **Reviews home deny set**: the literal path prefix pair `docs/reviews/` and `docs/history/reviews/`; both candidate homes of the open operator decision, both deny-committed by design, so the refusal is correct under either outcome; the pair is the exhaustive deny set, and any facts `reviews_dir` value or future home decision that resolves outside the pair must extend `REVIEWS_HOME_PREFIXES` in the same change; the match is byte-exact startswith on repo-relative forward-slash paths (the guard's matching precedent), and case-variant sibling directories are outside this accident-fence's scope, which backstops the gitignore layer rather than re-implementing it.
- **Reviews-home egress**: the never-suppressible guard finding for a staged or landing-added tracked path under the deny set; named after and shaped like the existing archive-egress class.
- **Runtime manifest**: `scripts/runtime-scripts.list`, the manifest-driven symlink deployment's entry list (92b7db1b); the operators' canonical pass that confirms deployed parity for loop-consumed scripts.
- **Landing tail**: any skill step that turns a worktree branch into a base-branch advance (execute-plan land-under-lock, execution blueprint final-merge, plans-skill self-landing by reference, unblock template by anchor delegation).
- **Shared helpers**: the guard's extracted scan primitives this plan prescribes: `deleted_paths(root, a, b)` (one name-status -z scan over a range, returning unquoted deleted paths and counting the old-side path of R and C records as deletions), consumed by `cmd_check_landing`, the `check-landed` subcommand, and the landing reviews-home scan; and `last_content_touch(root, path, a, b)` (the per-path log probe returning the newest touching commit in a range, or empty), the `check-landed` mode's foreign-content predicate, scoped to it so `cmd_check_landing`'s broad stale-arm evidence is preserved.
